| --- | --- | --- |

## 目录与发布

- `index.html`：站点入口页。
- `math-island/`：口算探险岛应用与独立资源，详细说明见 [应用 README](math-island/README.md)。
- 每个新增应用使用自己的目录和相对资源路径，再在入口页增加链接。

GitHub Pages 从 `main` 分支根目录发布。保留 `math-island/` 可保持现有应用网址稳定；其他应用可以使用 `/<应用名>/`，也可以在各自的 GitHub 项目仓库启用 Pages。

根目录中的旧版应用资源仅为历史兼容保留，入口页不依赖它们。后续口算应用更新只替换 `math-island/` 中的文件。
